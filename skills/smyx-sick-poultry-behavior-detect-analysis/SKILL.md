## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过畜禽舍固定摄像头的连续视频，识别鸡/猪等畜禽个体或群体的病态行为特征，输出结构化的病态行为清单与风险分级结果，为规模化养殖场提供比人工巡检更早的疾病早期发现依据。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 畜禽个体检测、定位与轨迹跟踪 |
| 2 | 站立困难 / 蹲卧 / 站姿摇晃识别 |
| 3 | 羽毛蓬松（家禽）/ 毛发竖立（猪）识别 |
| 4 | 离群独处行为识别（远离群体、边角静止） |
| 5 | 嗜睡 / 长时间闭目静止行为识别 |
| 6 | 食欲废绝行为识别（长时间远离食槽、不采食） |
| 7 | 群体活跃度评估与病态比例统计 |
| 8 | 病态行为综合风险等级输出（正常 / 关注 / 预警 / 高风险） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽舍固定摄像头视频 URL 或文件需要病态行为筛查时，默认触发本技能进行病态行为识别 |
| 🔎 明确分析意图 | 当用户明确提及病鸡识别、病猪识别、病态行为、羽毛蓬松、离群独处、嗜睡、食欲废绝、早期疾病发现、群体健康巡检等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史病态行为报告、历史病鸡病猪识别报告、病态行为识别清单、查询畜禽异常记录、显示所有病态行为报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

#### ⚠️ 强制数据获取规则（次高优先级）

> **橙色强约束：** 历史报告清单只允许从云端接口读取，不允许从本地记录、长期记忆或人工汇总中提取。

必须执行：

```bash

```

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 固定摄像头俯视/斜俯视覆盖畜禽舍主要活动区，画面稳定、避免频繁抖动 |
| 2 | 视频建议 30 秒~10 分钟连续拍摄，帧率不低于 15fps，便于行为跟踪 |
| 3 | 光照条件稳定，白天充足自然光或稳定人工光源，避免大面积过暗/过曝 |
| 4 | 单栏舍内目标个体清晰可见，尽量减少大面积遮挡（如密集堆叠或人员遮挡） |
| 5 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 6 | 尽量在群体日常状态（非饲喂/清扫等剧烈干扰期）内采集，行为特征更具代表性 |
