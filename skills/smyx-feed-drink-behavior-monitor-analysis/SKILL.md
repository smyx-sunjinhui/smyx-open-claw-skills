# 🐖 Livestock Feeding & Drinking Behavior Monitor | 畜禽采食/饮水行为监测

> 通过视频统计畜禽采食时长、饮水频次，异常时预警。
>
> **精准饲喂行为中枢** · 食槽/饮水器视频智能分析 · 采食时长与频次统计 · 基线对比 · 异常预警 · 历史报告云端查询

---

| 模块 | 内容 |
|---|---|
| 🏷️ 技能名称 | **畜禽采食/饮水行为监测** |
| 🎯 核心目标 | 基于食槽或饮水区域的固定摄像头视频，识别畜禽采食与饮水行为，统计每日采食时长、采食频次、饮水频次，并与个体历史基线对比，输出行为异常提醒 |

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过食槽或饮水区域的固定摄像头视频，量化畜禽的采食与饮水行为，比较其与个体历史基线的差异，为食欲下降的早期预警和精准饲喂管理提供客观的行为学数据支撑。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 食槽/饮水区域畜禽个体检测与定位 |
| 2 | 采食行为识别（低头进食、咀嚼、吞咽等动作特征） |
| 3 | 饮水行为识别（接触饮水器、抬头饮咽等动作特征） |
| 4 | 单次采食时长与采食频次统计 |
| 5 | 每日饮水频次与饮水节律统计 |
| 6 | 行为分布时序（早/中/晚三时段） |
| 7 | 与个体历史基线对比并输出偏差等级 |
| 8 | 采食/饮水行为异常提醒（轻度 / 中度 / 重度） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供食槽/饮水区域固定摄像头视频 URL 或文件需要行为统计时，默认触发本技能进行采食与饮水行为监测 |
| 🔎 明确分析意图 | 当用户明确提及采食时长、采食频次、饮水频次、食欲监测、饮水监测、食欲下降、精准饲喂、行为基线、行为异常等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史采食饮水报告、历史行为监测报告、采食饮水报告清单、查询畜禽行为记录、显示所有采食饮水报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

#### ⚠️ 强制数据获取规则（次高优先级）

> **橙色强约束：** 历史报告清单只允许从云端接口读取，不允许从本地记录、长期记忆或人工汇总中提取。

必须执行：

```bash
python -m scripts.smyx_feed_drink_behavior_monitor_analysis --list
```

| 类型 | 要求 |
|---|---|
| ✅ 必须 | 使用 `python -m scripts.smyx_feed_drink_behavior_monitor_analysis --list` 调用 API 查询云端的历史报告数据 |
| 🚫 严格禁止 | 从本地 `memory` 目录读取历史会话信息 |
| 🚫 严格禁止 | 手动汇总本地记录中的报告 |
| 🚫 严格禁止 | 从长期记忆中提取报告 |
| ✅ 输出格式 | 必须统一从云端接口获取最新完整数据，然后以 Markdown 表格格式输出结果 |

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 固定摄像头正对食槽或饮水器，拍摄角度稳定，避免大幅位移或频繁调整视角 |
| 2 | 画面中食槽/饮水器全景可见，能清晰观察畜禽头部与饮食器具的接触动作 |
| 3 | 光照条件稳定，白天充足自然光或稳定人工光源，避免强逆光和大面积过曝 |
| 4 | 视频建议 15 秒~5 分钟，帧率不低于 15fps，覆盖典型采食/饮水时段 |
| 5 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 6 | 尽量避免人员进出、清扫作业等大面积遮挡影响行为统计 |

### 🔐 用户身份处理（内部自动完成）

> **绿色安全原则：** 用户身份参数由系统内部自动处理，**不得向用户展示、询问或要求输入任何身份标识**。

| 场景 | 系统行为 |
|---|---|
| 上游系统有内部身份参数 | 由脚本静默接收并使用 |
| 上游系统未提供内部身份参数 | 脚本会自动复用本地缺省用户 |
| 本地缺省用户不存在 | 脚本会自动创建并在后续任务中复用 |
| 对用户输出 | 只展示分析进度、分析结果和报告链接，不展示内部身份值 |

## 🧪 标准流程 | Standard Flow

| 步骤 | 阶段 | 执行动作 |
|---:|---|---|
| 1 | 📥 准备食槽/饮水器视频输入 | 提供本地文件路径或网络 URL；确保画面稳定、符合采集要求 |
| 2 | 🔐 系统自动完成身份关联 | 无需用户输入任何身份参数；不在回复中展示内部身份值 |
| 3 | ⚙️ 执行采食/饮水行为监测 | 调用 `-m scripts.smyx_feed_drink_behavior_monitor_analysis` 处理输入（**必须在技能根目录下运行脚本**） |

### ⚙️ 脚本参数说明

| 参数 | 含义 | 备注 |
|---|---|---|
| `--input` | 本地食槽/饮水区域图像/视频文件路径 | 适用于本地文件分析 |
| `--url` | 网络食槽/饮水区域图像/视频 URL 地址 | API 服务自动下载 |
| `--pet-type` | 类别标识（畜禽场景保持 other） | 默认 `other`，按需填写 |
| `--list` | 显示历史分析报告清单 | 可以输入起始日期参数过滤数据范围 |
| `--api-url` | API 服务地址 | 可选，使用默认值 |
| `--detail` | 输出详细程度 | `basic` / `standard` / `json`，默认 `json` |
| `--output` | 结果输出文件路径 | 可选 |
