# 🔊 Livestock Vocalization Health Analysis | 畜禽声纹健康分析

> 通过叫声分析识别畜禽呼吸道疾病等健康问题。
>
> **非接触式群体健康筛查中枢** · 畜禽舍音频智能分析 · 咳嗽/喘息/尖叫/嘶哑识别 · 呼吸道健康风险提示 · 历史报告云端查询

---

| 模块 | 内容 |
|---|---|
| 🏷️ 技能名称 | **畜禽声纹健康分析** |

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过对畜禽舍音频/含声轨视频的声学特征提取与建模，识别咳嗽、喘息、痛苦尖叫、嘶哑等异常叫声事件，输出结构化的呼吸道健康风险提示，为大群体养殖场提供非接触式的健康筛查手段。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 音频段有效性检测与噪声过滤 |
| 2 | 叫声事件切分与时长/强度提取 |
| 3 | 频谱/音调特征提取（基频、共振峰、包络） |
| 4 | 咳嗽声识别 |
| 5 | 喘息 / 呼吸急促声识别 |
| 6 | 痛苦尖叫 / 嘶哑叫声识别 |
| 7 | 群体异常声纹密度统计（单位时间异常次数） |
| 8 | 呼吸道健康风险等级输出（正常 / 关注 / 预警 / 高风险） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽舍音频或含声轨视频 URL/文件需要声纹健康分析时，默认触发本技能 |
| 🔎 明确分析意图 | 当用户明确提及畜禽叫声分析、咳嗽识别、喘息识别、呼吸道疾病预警、群体健康筛查、非接触健康巡检等关键词，并且上传了音频或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史声纹健康报告、历史畜禽叫声分析报告、声纹健康分析清单、查询呼吸道预警记录、显示所有声纹健康分析报告 |

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者音频/视频文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

## 🎙️ 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 采集设备建议使用固定式指向麦克风或摄像头自带高保真拾音，安装在畜禽群体正上方或斜上方 |
| 2 | 采样率建议 ≥16kHz（推荐 44.1kHz/48kHz），采样位深 ≥16bit，避免过强压缩 |
| 3 | 音频时长建议 30 秒~10 分钟，覆盖群体自由活动或休息安静时段 |
| 4 | 尽量减少风机、清粪机、饲喂机等大功率设备的持续背景噪声，避免掩盖异常叫声 |
| 5 | 环境背景相对稳定，避免大量人员喊话、金属碰撞等突发噪声干扰 |
| 6 | 支持格式：wav/mp3/m4a/aac 音频；mp4/avi/mov 含声轨视频；单文件不超过 10MB |
| 7 | 若采用含声轨视频，请确认声轨音量正常且未被静音，画面对识别本身不做强制要求 |
