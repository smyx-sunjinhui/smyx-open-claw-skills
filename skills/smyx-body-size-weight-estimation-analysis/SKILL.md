# 📏 Livestock Body Size & Weight Estimation | 畜禽体长/体重估测

> 通过视频视觉估测体长、体重，追踪育肥进度。
>
> **无接触育肥监测中枢** · 畜禽侧视图像/视频智能分析 · 体长/体高/胸围识别 · 参照物尺寸换算 · 体重与育肥阶段估测 · 历史报告云端查询

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过畜禽侧视图像或视频帧，识别关键体尺特征并结合参照物换算实际尺寸，估算个体的体长、体高、胸围与体重，同时给出所处育肥阶段判定，为规模化猪、牛、羊养殖的育肥进度追踪与出栏时机判断提供无接触视觉参考。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 畜禽个体检测与侧视姿态判定 |
| 2 | 参照物识别与像素-实际比例标定 |
| 3 | 体长估测（吻端-尾根 / 头-臀水平投影） |
| 4 | 体高估测（肩高 / 髻甲高度） |
| 5 | 胸围/体宽视觉估测 |
| 6 | 体型参数-体重回归估测（按畜种模型） |
| 7 | 育肥阶段判定（保育 / 育成 / 育肥 / 接近出栏） |
| 8 | 估测结果置信度与可用度提示（受遮挡/姿态影响的说明） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽侧视图像/视频 URL 或文件需要体尺/体重估测时，默认触发本技能 |
| 🔎 明确分析意图 | 当用户明确提及体重估测、体长测量、育肥进度、出栏时机判断、无接触称重、视觉称重等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史体重估测报告、历史体尺估测报告、育肥进度清单、查询畜禽体重记录、显示所有体长体重估测报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

#### ⚠️ 强制数据获取规则（次高优先级）

> **橙色强约束：** 历史报告清单只允许从云端接口读取，不允许从本地记录、长期记忆或人工汇总中提取。

必须执行：

```bash
python -m scripts.smyx_body_size_weight_estimation_analysis --list
```

| 类型 | 要求 |

| 🚫 严格禁止 | 从本地 `memory` 目录读取历史会话信息 |

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 目标畜禽以完整侧视姿态入镜（吻端至尾根、蹄底至髻甲均在画面内），避免大角度俯仰 |
| 2 | 拍摄距离建议 1.5m～5m，畜禽身体轮廓清晰可见，尽量避免其它个体大面积遮挡 |
| 3 | 画面中需包含已知尺寸的参照物（如围栏杆间距、地砖、标定板等），便于像素-实际尺寸换算 |
| 4 | 光照条件稳定，避免强逆光和大面积过暗/过曝，保证轮廓边缘清晰 |
| 5 | 视频建议 5~30 秒稳定拍摄，包含至少 1~2 帧完整侧视静止画面 |
| 6 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 7 | 目标畜禽尽量处于自然站立状态（四肢着地、身体伸展），避免弓背、卧地或走动模糊 |
